# Fokusveckan

En veckoplanerare för vuxna med ADHD, med belöningssystem, avatar, fokusövningar och påminnelser.

## Ladda ner appen

Gå till **Releases** till höger på den här sidan och ladda ner den senaste `Fokusveckan.apk` på din Android-mobil.

## Installera på Android

1. Öppna länken till senaste versionen på mobilen och tryck på `Fokusveckan.apk`.
2. Öppna filen när den laddats ner.
3. Om mobilen frågar: tillåt installation från den här källan (Chrome eller Filer).
4. Tryck **Installera**.
5. När appen frågar om aviseringar, tryck **Tillåt** så att påminnelserna fungerar.

Android kan visa en varning om att appen kommer från en okänd utvecklare. Det är normalt för testversioner som inte ligger på Google Play.

## Så byggs appen

Varje gång något ändras på grenen `main` bygger GitHub en ny APK automatiskt (se fliken **Actions**). Appen ligger i `www/index.html`.
